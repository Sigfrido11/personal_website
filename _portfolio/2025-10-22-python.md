# MVA Analysis using a Boosted Decision Tree

This post presents an application of supervised machine learning techniques, specifically a **Boosted Decision Tree (BDT)**, used to improve the selection of signal events associated with the neutral $B_s^0$ meson in real data collected by the LHCb experiment at CERN.

The main goal of the analysis is to efficiently separate **rare signal events** from a **dominant combinatorial background**, which significantly complicates the direct identification of the decay process.

The BDT model is trained on a set of kinematic and topological variables describing the decay products, allowing the construction of a powerful discriminant that substantially improves the signal-to-background separation compared to traditional cut-based methods.

<div class="cell markdown">
<p>The overall strategy of the analysis is:</p>
<ol>
<li>Define a <strong>signal window</strong> and a <strong>background
sideband</strong> for training.</li>
<li><strong>Select features</strong> (variables) that discriminate
signal from background.</li>
<li>Train a <strong>boosted decision tree (BDT)</strong> classifier on
those features.</li>
<li><strong>Optimize the classification threshold</strong> to maximize
signal significance.</li>
<li>Apply the cut, fit the resulting mass distribution, and extract the
<span class="math inline"><em>B</em><sub><em>s</em></sub></span>
yield.</li>
</ol>
</div>

<section id="23-simulation-reweighting" class="cell markdown">
<h3>2.3 Simulation reweighting</h3>
<p>Monte Carlo simulations at LHCb are not perfect: the decay kinematics
are modelled with theoretical approximations, and the detector response
is only approximately reproduced. To correct for known kinematic
mismodelling, each simulated event carries a
<code>kinematic_weights</code> factor. These weights should be applied
in all comparisons and training steps.</p>
<p>Another potential source of mismodelling is differences between data
and simulation in the input variables that will be used for
classification. To check this without access to <span
class="math inline"><em>B</em><sub><em>s</em></sub></span> signal data
(the signal is not yet visible), the <span
class="math inline"><em>B</em><sup>0</sup> → <em>ψ</em>(2<em>S</em>) <em>K</em><sub><em>S</em></sub></span>
decay is used as a control channel. This decay has a very similar
topology and kinematics to the <span
class="math inline"><em>B</em><sub><em>s</em></sub></span> signal, and
it is abundant enough to already be visible in data. Its events in data
are isolated using <strong>sWeights</strong>
(<code>sweights_sig</code>), a statistical technique that subtracts
background contributions based on the mass fit. The resulting weighted
data distribution represents pure <span
class="math inline"><em>B</em><sup>0</sup></span> signal events.</p>
<p>The effect of the kinematic weights on the simulation mass
distribution is shown first, followed by a comparison of the <span
class="math inline"><em>B</em><sup>0</sup></span> data (with sWeights)
against the unweighted data.</p>

<section id="3-feature-selection" class="cell markdown">
<h2>3. Feature selection</h2>
<p>The goal here is to find a set of variables that are good at
separating signal from background, and at the same time are well
described by the simulation. Three conditions must be satisfied for a
variable to be included:</p>
<ol>
<li>Good agreement between <span
class="math inline"><em>B</em><sup>0</sup></span> data and <span
class="math inline"><em>B</em><sup>0</sup></span> simulation (so the
classifier learns signal vs. background, not data vs. simulation).</li>
<li>Strong discrimination between signal simulation and the upper
sideband background.</li>
<li>Low correlation with the <span
class="math inline"><em>B</em><sub><em>s</em></sub></span> reconstructed
mass (to avoid biasing the final fit).</li>
</ol>
<h3 id="31-selecting-well-modelled-variables">3.1 Selecting
well-modelled variables</h3>
<p>For each variable, the KS distance between the <span
class="math inline"><em>B</em><sup>0</sup></span> data (sWeighted) and
<span class="math inline"><em>B</em><sup>0</sup></span> simulation
(kinematic weights) is computed using weighted CDFs. Variables with a KS
distance above 0.5 are considered too poorly modelled and are
excluded.</p>

not trained on it.</p>

<section id="5-threshold-optimization" class="cell markdown">
<h2>5. Threshold optimization</h2>
<p>The BDT output is a continuous score between 0 and 1. A threshold
must be chosen to split events into selected (signal-like) and rejected
(background-like). The optimal cut is found by maximizing a
<strong>figure of merit (FOM)</strong> based on signal significance:</p>
<p><span class="math display">$$s = \frac{\epsilon_{\text{sig}}}{5/2 +
\sqrt{n_{\text{bkg}}}}$$</span></p>
<p>where <span class="math inline"><em>ϵ</em><sub>sig</sub></span> is
the signal efficiency and <span
class="math inline"><em>n</em><sub>bkg</sub></span> is the estimated
number of background events remaining in the signal region after the
cut.</p>
<p>The number of background events in the signal region is estimated by
integrating the exponential background shape (fitted to the upper
sideband) over the signal window, scaled by the fraction of background
events passing the BDT cut. The FOM is evaluated for 100000 equally
spaced threshold values between 0 and 1.</p>
</section>

<section id="64-full-fit-to-selected-data" class="cell markdown">
<h3>6.4 Full fit to selected data</h3>
<p>The full mass distribution of BDT-selected data is fitted with a
model made of three components:</p>
<ul>
<li>A Gaussian for the <span
class="math inline"><em>B</em><sup>0</sup></span> peak</li>
<li>A Gaussian for the <span
class="math inline"><em>B</em><sub><em>s</em></sub></span> peak</li>
<li>An exponential for combinatorial background</li>
</ul>
<p>Each Gaussian is initialized from the shape parameters obtained from
the simulation fits. All parameters are left free in the final fit.
Poissonian uncertainties are used as bin errors (bins with zero events
are given an error of 1 to avoid division by zero). The fit quality is
evaluated with a <span
class="math inline"><em>χ</em><sup>2</sup>/<em>n</em><sub>dof</sub></span>
statistic.</p>

<section id="66-signal-significance" class="cell markdown">
<h3>6.6 Signal significance</h3>
<p>With the fit converged, the <span
class="math inline"><em>B</em><sub><em>s</em></sub></span> signal is now
visible in the data. The statistical significance of the observation is
estimated using a simple proxy:</p>
<p><span class="math display">$$m =
\frac{n_{\text{sig}}}{\sqrt{n_{\text{sig}} +
n_{\text{bkg}}}}$$</span></p>
<p>where <span class="math inline"><em>n</em><sub>sig</sub></span> and
<span class="math inline"><em>n</em><sub>bkg</sub></span> are the signal
and background yields estimated by integrating the respective fit
components over the signal window. The integration uses the Gaussian and
exponential fit parameters, and both a <span
class="math inline"><em>B</em><sup>0</sup></span> contribution and the
exponential combinatorial background are counted as background.</p>
</section>
<div class="cell markdown">
<p>The final significance is also cross-checked by a simple
event-counting method: the number of selected events inside the signal
window is counted, and the expected background is estimated by scaling
the number of upper sideband events that pass the BDT cut into the
signal window, corrected for the width ratio. Both methods give
consistent results.</p>
</div>
